# Skills

* When running any git commands or writing commit messages, always load and use the git-commit skill.

# Command Policy

## Preferred Tools

* Use `fd` instead of `find` for file search.
* Use `rg` (ripgrep) instead of `grep` for text search.
* Use `pnpm` instead of `npm` or `yarn` for package management.

## Rules

* Always use the preferred tool when applicable.
* Use the native syntax of the preferred tool.
* Only use legacy tools if the preferred tool cannot accomplish the task.
